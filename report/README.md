- Usecase diagram's purpose is to answer the question: "What does the user want to achieve with the system?", not "How does the system achieve it?". E.g. "User wants to see the list of friend requests" is a usecase, but "Friend request list can be filtered by date" is not a usecase, it's a feature of the usecase.
- trigger vs pre-condition: trigger is something that ACTIVATE the usecase to run. pre-condition is something that an usecase MUST HAVE to be able to run.
